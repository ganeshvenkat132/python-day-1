This python proagram validates a user profile based on four inputs
1.full name
2.email id
3.mobile number
4.age
this profile is considered VALID only if all validation rules are satisfied ,otherwise it is marked INVALID.

VALIDATION RULES
1.full name 
   must contaion at least two words
   must not start or end with a space
2.email id
   must contaion exacylt one @ symbol
   must contain a . (dot)
   must not satrt with @
3.mobile number
   must be exactly 10 digits
   must contain only numbers
   must not satrt with 0
4.age
  must be greater than 18 and less than or equal to 60
  
LOGIC 
1.take user inputs
2.check each condition one by one
3.if any condition fails-->INVALID
4.if all conditions pass--> VALID
